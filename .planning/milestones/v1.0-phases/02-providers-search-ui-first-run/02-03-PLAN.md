<objective>
Make search cheap and honest. A Go search.Service in front of every provider caches trending (10 min) and search (5 min) pages, refuses to retry into a 429, and applies the dedupe policy; the frontend cancels superseded searches and renders every loading, empty and error state from the UI-SPEC with exact copy, scoped per provider.

Purpose: SRCH-06 (free keys last; clear retry time), SRCH-07 (per-provider errors, isolation), SRCH-03 (trending cache) and ONBD-05 (dedupe only for non-Klipy). After this plan a user hitting a dead or rate-limited provider sees what happened and when to retry, and repeat views cost no requests.
Output: internal/search, GifService on top of it, fixture scenario words, lib/errors.ts (+ node tests), StateMessage.svelte, cancellation in lib/api.ts, scripts/uat/03-states.js.
</objective>
