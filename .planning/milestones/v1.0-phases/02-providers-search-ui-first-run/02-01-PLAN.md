Build the one path end to end, production quality, Finer Gifs only (per D-16: all provider HTTP in Go).

Go domain:
1. internal/provider/provider.go exactly as in `<interfaces>`. Error() must never include a URL, query, key or body (Wails copies err.Error() into the JS call message verbatim, RESEARCH Pattern 1). MarshalError uses errors.As and json.Marshal of the struct.
2. internal/provider/httpx/httpx.go: GetJSON per RESEARCH "httpx classification (core)": NewRequestWithContext GET, User-Agent header, c.Do; on transport error return ctx.Err() if the context is done, else a fresh *provider.Error with Kind Timeout (net.Error Timeout()) or Network — never wrap or format the transport error (its text contains the full URL). Read at most 8 MB. 429 -> RateLimited with retryAfter parsed only here (strconv.Atoi, then http.ParseTime; <=0 or garbage -> 0). Other non-2xx -> HTTP with Status. 2xx with empty/whitespace body or a JSON decode failure -> HTTP with Status. Remap as in `<interfaces>`. Log nothing in httpx.
3. internal/provider/finergifs/finergifs.go: Client per `<interfaces>`. Search: cursor "" means start 0; a non-integer or negative cursor returns &provider.Error{Kind: HTTP, Provider: FinerGifs} (never silently restart). Response struct: results []struct{ Fields struct{ Name, Text, Fileid string } } and hits *struct{ Found, Start int }; a nil results slice is a typed HTTP error (malformed), zero results is a valid empty page. Each item: fileid must match ^[A-Za-z0-9._-]+$, else the whole response is a typed HTTP error; URL = MediaBase + "/" + fileid + ".gif" for both PreviewURL and DownloadURL (the only rendition, RESEARCH); Title = text, fallback name. Next = strconv.Itoa(start+len) when hits != nil ? start+len < found : len == 24; else "". Trending returns Page{Items: []provider.Gif{}} with no request. Results are kept in returned order; no reordering or filtering here (D-15; same-page dedupe arrives with the search service in plan 02-03).
4. internal/provider/fakeapi/fakeapi.go: Handler(Options) serving `GET /finer/search` with 60 deterministic fixture items (fileid "office-<n>", text "Office moment <n>") honoring start and size and returning hits {found: 60, start}, and `GET /media/<name>.gif` generating a 2-frame 32x32 animated GIF with image/gif (palette color from a hash of name) with Content-Type image/gif. Any query containing "empty" returns zero results with found 0. When Options.FinerDown is set, /finer/search returns HTTP 530 text/plain "error code: 1033". Scenario words beyond "empty" are added in plan 02-03.
5. internal/provider/finergifs/finergifs_test.go: httptest.NewServer(fakeapi.Handler(fakeapi.Options{})) -> Search("dwight","") returns 24 items with Next "24", Search(…,"48") returns 12 items with Next "", Trending makes no request (use a handler wrapper that counts hits).
