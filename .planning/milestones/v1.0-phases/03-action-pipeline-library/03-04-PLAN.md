- Primary noun: the download destination folder (a value supplied by `ActionService.DownloadsDir func() string`), not "Downloads".
- Decision: promote. - Invariant test (accepted, Task 1): a Save into an arbitrary t.TempDir() destination produces the same naming, collision and validation behavior as the default, and DownloadResult.Folder equals that directory's base name.
</assumption_delta_decision>
