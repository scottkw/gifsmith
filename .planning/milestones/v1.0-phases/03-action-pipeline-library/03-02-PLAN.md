<objective>
Add the Raycast-style ⌘K action menu: a popover anchored to the selected tile that lists every action available for the selected GIF in the locked order, filters as you type, runs the highlighted row on ↵ and closes on Esc. It runs actions through one App dispatcher, so later plans add rows (Download, Square, Favorite, Details, Remove/Clear Recents) to the table without touching the menu.

Purpose: ACTN-07, and the menu entry points for the ACTN-03/ACTN-04 actions that have no direct shortcut (Paste Link, Paste Markdown, Copy Page Link).
Output: lib/actions.ts and lib/popover.ts (pure, node-tested), ActionMenu.svelte, App.svelte dispatcher and mode precedence, footer ⌘K hint, updated 02-keyboard.js, new scripts/uat/08-action-menu.js.
</objective>

- lib/actions.ts:
  - `type ActionId = 'copy' | 'paste' | 'copyLink' | 'pasteLink' | 'copyMarkdown' | 'pasteMarkdown' | 'copyPage' | 'open' | 'download' | 'copySquare' | 'pasteSquare' | 'favorite' | 'details' | 'removeRecent' | 'clearRecents'` (the full union now; rows for download, square, favorite, details, removeRecent, clearRecents are added to `ROWS` by plans 03-04, 03-05, 03-06 and 03-07 when their handlers exist)
  - `type ActionCtx = { gif: Gif; tab: 'provider' | 'favorites' | 'recents'; inDetails: boolean; favorited: boolean }`
  - `type ActionRow = { id: ActionId; label: string; hint: string; keys: string; group: number; destructive: boolean }` (`hint` is display glyphs like "⌘⇧C", `keys` is the aria-keyshortcuts value like "Meta+Shift+C", "" when none)
  - `buildActions(ctx: ActionCtx): ActionRow[]` (locked order, omissions applied)
  - `filterActions(rows: ActionRow[], text: string): ActionRow[]` (trimmed, case-insensitive substring of label)
- lib/popover.ts: `MENU_W = 320`, `placeMenu(tile: {x: number; y: number; width: number; height: number}, col: number, menuH: number, win?: {w: number; h: number}): {left: number; top: number}` (cols 0-1 -> left = tile right + 8; cols 2-3 -> left = tile left - 8 - 320; top = tile top; clamp so the popover stays >= 8px inside the window on every side; default win 720x480)
- ActionMenu.svelte props: `rows: ActionRow[]`, `left: number`, `top: number`, `onrun: (id: ActionId) => void`, `onclose: () => void`; exposes `focus()`
- App.svelte: `menuOpen` state, `runAction(id: ActionId)` single dispatcher used by the menu and every shortcut
</interfaces>
