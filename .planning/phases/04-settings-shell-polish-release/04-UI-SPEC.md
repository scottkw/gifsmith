# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**This contract extends `02-UI-SPEC.md` and `03-UI-SPEC.md`. It does not redefine them.** The 720×480 panel, its four regions (search 48, tabs 36, content 364, footer 32), the 4/8/16/24/32 spacing scale, the 4 type sizes and 2 weights, the color tokens, the action menu, Details, library tabs, toasts and every S/E/K/C/T/F row still hold. This document covers only what Phase 4 adds or changes. Rows that change an earlier rule say **Amends 02** or **Amends 03**.

Surfaces this phase:
1. **A new Settings window** (second Wails window, normal titled window, not the NSPanel). Six panes: General · Keys · Hotkeys · Search · Downloads · About.
2. **Panel changes**: grid size (3/4/5 columns), configurable Enter / ⌘Enter actions, the Klipy file-action gate (RELS-04), Reduce Motion stills, theme override, ⌘, to open Settings, and the Phase 3 UI-review polish.
3. **Release surfaces**: tray menu, DMG window, About credits.

Sources: 04-CONTEXT.md (locked decisions), 03-UI-SPEC.md and 02-UI-SPEC.md (baseline), 03-UI-REVIEW.md and `.planning/todos/pending/phase-3-ui-review-polish.md` (polish folded in), 03-REVIEW-DISPOSITION.md (IN items), REQUIREMENTS.md (SETT-01..06, SRCH-09, ACTN-08, SHEL-05, SHEL-06, RELS-01..04), the code as built (`frontend/src/app.css`, `components/*.svelte`, `lib/actions.ts`, `lib/popover.ts`, `lib/grid.ts`, `lib/errors.ts`, `internal/shell/shell.go`, `internal/provider/provider.go`, `build/darwin/Taskfile.yml`), and `LICENSE` (credit names). Items marked **[default]** are researcher choices the upstream artifacts do not cover. "Open Questions" lists the ones the user may want to revisit; none block planning.

## Settings Window (SETT-01)

### Window

| Property | Value |
|----------|-------|
| Kind | Normal titled Wails window (standard title bar and traffic lights), not a panel. Not resizable. Content size **640×520** |
| Title | `Gifsmith Settings` **[default]** |
| Opened by | Tray menu `Settings…`; ⌘, in the panel (panel hides first); `Test` never opens it |
| Activation | Showing Settings activates the app (accessory policy, still no Dock icon) so the window is key, typing works, and ⌘V pastes into the key field via the Edit menu role |
| Position | First show of a launch: centered on the display with the mouse cursor. Later shows: where the user left it |

### Settings window keyboard

| Key | Behavior |
|-----|----------|
| Tab / ⇧Tab | Sidebar (one tab stop, the selected item) → pane controls in DOM order → back |
| ↑ ↓ | In the sidebar: move to the previous / next pane and show it at once, clamped (no wrap) |
| ⌘W | Close the window |
| Esc | Cancels the innermost transient state only: a recording hotkey field, an open key editor, or a remove confirmation. Otherwise does nothing (macOS settings windows do not close on Esc) |
| ⌘, | Settings already frontmost: nothing |
| ⌘V / ⌘C / ⌘X / ⌘A / ⌘Z | Native text editing in the key field (Edit menu role) |

**Automatic paste status (SETT-05):**

| State | Control column |
|-------|----------------|
| Allowed | `check` icon 12×12 + `On`, 14px Body `--success`. Helper: copy G4 |
| Not allowed | `Off`, 14px Body `--text-secondary`, then 8px, then `.btn-primary` `Grant Access…`. Helper: copy G5 |

**Default actions (ACTN-08):**

- Options, in this order: `Copy GIF`, `Paste GIF`, `Copy Link`, `Paste Link`, `Copy Markdown`, `Paste Markdown`, `Download GIF`. Square actions are not offered **[default]** (crop is slow and does not apply to Clips).
- Choosing for one key the action the other key already has swaps the two, so ↵ and ⌘↵ always differ **[default]**.
- Mapping at run time: for Clips, GIF actions run their MP4 form (`Copy MP4`, `Paste MP4`, `Download MP4`). For Klipy items while file actions are gated (RELS-04), any file action (`Copy GIF`, `Paste GIF`, `Download GIF`) runs as `Copy Link` for ↵ and `Paste Link` for ⌘↵; text actions run as chosen.
- Helper under the pair: copy G6 (shown while the Klipy gate is closed), else none.

### Keys (SETT-02)

Two cards, GIPHY then Klipy, 16px apart. No section hairlines on this pane.

```
┌ card: --surface, radius 8, padding 16, width 432 ───────────────────────┐
│ GIPHY  (14px 600)                             ✓ Saved · ends in 3fQx    │
│ Used for GIPHY and GIPHY Clips. Free keys allow 100 requests per hour.  │  12px secondary
│ [Change Key…] [Test] [Remove]                         Get a free key ↗  │  32px row
│ (message line, 16px: result / error)                                    │
└─────────────────────────────────────────────────────────────────────────┘
```

| Part | Value |
|------|-------|
| Title line | Provider name `GIPHY` / `Klipy`, 600 14px `--text`, left. Status right-aligned, 12px Label |
| Status: Saved | `check` 12×12 + `Saved · ends in {last4}` in `--success`. `{last4}` comes from Go (last 4 characters only; the webview never receives the full key) |
| Status: Not set | `Not set` in `--text-secondary` |
| Status: Rejected | `alert-circle` 12×12 + `Rejected` in `--destructive` (set by a failed Test or a `key_rejected` from search, S13) |
| Status: Testing | 12px spinner + `Testing…` in `--text-secondary` |
| Description | 4px below title, 12px Label `--text-secondary`. GIPHY: `Used for GIPHY and GIPHY Clips. Free keys allow 100 requests per hour.` Klipy: `Used for Klipy. Free keys allow 100 requests per hour.` |
| Action row | 16px below the description. Buttons left (8px gap), `Get a free key ↗` link right (GIPHY developer dashboard / Klipy Partner Panel, existing `GIPHY_KEY_URL` / `KLIPY_KEY_URL`) |
| Buttons, Not set | `.btn-primary` `Add Key…` |
| Buttons, Saved / Rejected | `.btn-secondary` `Change Key…`, `.btn-secondary` `Test`, `.btn-secondary` `Remove` |
| Message line | 8px below the action row, 16px tall, 12px Label, one line, ellipsis, `role="status"` (success) / `role="alert"` (error). Empty → the line keeps its height |

**Edit state (`Add Key…` / `Change Key…`):** the action row becomes `[key field, flex 1] [Save Key] [Cancel]` (8px gaps). The field takes focus, placeholder `Paste your {Provider} API key`. `Save Key` is `.btn-primary`, disabled while the field is empty; while verifying it reads `Verifying…` with a spinner and the field is read-only. Saving runs the Phase 2 `SaveKey` path (test call, then Keychain). Success: field cleared, status `Saved · ends in {last4}`, message `Saved. {Provider} is ready.` (success, 4 s). Failure: field keeps the text, selected, error K2–K4 / F9 in the message line. Esc or `Cancel` closes the editor and restores the previous row. ↵ in the field submits.

**Test:** runs one first-page trending call with the stored key (costs 1 request; the result seeds the trending cache). Results: K-T1..K-T4 in the message line. `Test` is disabled while testing.

**Remove (confirmation, inline):** the action row becomes the confirmation:

`Remove your {Provider} key?` (14px Body `--text`) on its own line, the consequence (12px Label `--text-secondary`, copy row) below it, then `[Cancel] [Remove Key]` right-aligned (`.btn-secondary`, `.btn-destructive`). Focus moves to `Cancel`. Esc = Cancel. `Remove Key` deletes the Keychain item, sets the status `Not set`, emits an event so the panel's tab shows its setup card (and Clips are re-probed off), and shows `Removed. Add a key to use {Provider} again.` (secondary tone, 4 s).

### Hotkeys (SETT-03, SHEL-06)

Three stacked rows, one section each:

| Row label | Default | Buttons after the recorder | Fires |
|-----------|---------|----------------------------|-------|
| `Open Gifsmith` | ⌃⌥⌘G | `Test`, `Reset to Default` (disabled when already ⌃⌥⌘G) | Toggle the panel (unchanged) |
| `Open Favorites` | not set | `Test` (disabled when unset), `Clear` (disabled when unset) | Show the panel on Favorites (⌘5). If the panel is already showing Favorites, hide it |
| `Open Recents` | not set | `Test` (disabled when unset), `Clear` (disabled when unset) | Show the panel on Recents (⌘6). If already showing Recents, hide it |

Helper under the last row (section-level, 12px `--text-secondary`): copy H8.

**Recorder field:**

| Property | Value |
|----------|-------|
| Size | 160×32, radius 6px, background `--bg`, 1px `--control-border`, centered text, `role="button"`, `aria-label="{Row label} shortcut"`, `aria-describedby` → the row's helper/error |
| Idle, set | Glyphs in macOS order `⌃⌥⇧⌘` then the key, 14px Body `--text` (e.g. `⌃⌥⌘G`) |
| Idle, unset | `Not set`, 14px Body `--text-secondary` |
| Recording | Text `Type shortcut…` in `--text-secondary`, replaced live by the modifiers being held (`⌃⌥⌘`). Accent ring shown for the whole recording (also when started by mouse): `outline: 2px solid var(--accent); outline-offset: 2px` |
| Start | Click, or Space / ↵ when focused |
| Accept | A non-modifier key pressed with at least one of ⌘ ⌥ ⌃ (⇧ allowed in addition). Keys: letters, digits, F1–F20, Space, punctuation, arrows. Stored as a Wails accelerator (`Ctrl+Option+Cmd+G`); letters are layout-aware |
| Register | Immediately on accept. Go unregisters the old binding, registers the new one, and on failure re-registers the old one. The field shows the new combo only after success |
| Suspend | While any recorder is recording, Go suspends all Gifsmith hotkeys (so pressing the current combo is captured, not fired) and restores them when recording ends |
| Cancel | Esc, blur, Tab, or the window losing focus. Previous value shown, no error |
| Backspace / Delete (no modifiers) | Favorites / Recents: clears the binding (same as `Clear`). Open Gifsmith: ignored, keeps recording |
| Missing modifier | Keeps recording; error H1 |
| Duplicate inside Gifsmith | Stops recording, old binding kept; error H2 |
| System shortcut | `⌘Q ⌘W ⌘H ⌘M ⌘Tab ⌘Space ⌃Space ⌘⇧3 ⌘⇧4 ⌘⇧5` refused; error H3 **[default]** |
| Registration failed | Old binding kept; error H4 (or H4b when there was no old binding) |

**Test [default interpretation of the locked "Test button that opens the panel to confirm"]:** pressing `Test` puts the row into a 5 s listening state: helper becomes `Press {combo} now…` (secondary). If the global hotkey callback fires within 5 s, the panel opens as the hotkey normally would and the row shows H6 (success). If not, H7 (error). This is the only way to detect a clash with another app, because Carbon registration succeeds even when the combo is taken. Esc cancels listening.

**Tray menu reflects the binding:** the `Open Gifsmith` tray item shows the current Open hotkey as its key equivalent when the menu API supports it.

## Panel Changes

### Grid size (Amends 02 Tile / Grid, Amends 03 Library grid)

| Size | Columns | Tile (w × h) | Row stride | Skeleton tiles (S2) |
|------|---------|--------------|------------|---------------------|
| Small | 5 | 1fr (≈131) × 112 | 120 | 10 |
| Medium (default) | 4 | 1fr (166) × 144 | 152 | 8 (unchanged) |
| Large | 3 | 1fr (224) × 192 | 200 | 6 |

- Grid keeps 16px side padding and 8px gaps; columns are `repeat(N, 1fr)` across 688px, so Medium is exactly the Phase 2 166px.
- **Which size applies:** `Trending` size when a provider tab shows trending (empty query); `Search results` size when it shows search results. Favorites and Recents use the `Search results` size **[default]**.
- Keyboard math takes the column count as a parameter (`lib/grid.ts` and library section movement). Selection index is kept on a size change.
- Paging sentinel and "near the end" thresholds are measured in rows, unchanged.
- Badges, busy overlay and selection ring are unchanged at all sizes. The overlay spinner stays 16px.

### Action menu placement (Amends 03)

- Opens to the right of the tile when `tile.right + 8 + 320 ≤ 712`, otherwise to the left (`tile.left − 8 − 320`), then clamped 8px inside the window. Replaces the "columns 1–2 / 3–4" rule so it works for 3, 4 and 5 columns. In Large, the middle column's menu may overlap its tile (accepted).
- **Polish (P19):** the vertical clamp keeps the menu's bottom at least 8px above the footer (bottom ≤ 440), so the footer attribution stays visible while the menu is open. Same clamp for `placeInDetails`, which now uses the menu height.
- **Polish (P15):** right-click (`contextmenu`) on a tile selects it, then opens the menu anchored to it (same placement). Right-click on the Details preview opens the menu in its Details position. `preventDefault` only on tiles and the preview.

### Configurable Enter / ⌘Enter (ACTN-08)

- ↵ runs the Primary action, ⌘↵ the Secondary action (as mapped above for Clips and gated Klipy items).
- **Action menu hints:** each row shows one hint. `↵` goes on the row that ↵ will run, `⌘↵` on the row that ⌘↵ will run, otherwise the row's own shortcut (⌘⇧C, ⌘S…). Rows other than those two never show `↵` or `⌘↵`. Row order is unchanged.
- **Footer hints (Amends 03):** `↵ {primary short}   ⌘↵ {secondary short}   ⌘K Actions` on provider tabs; `↵ {primary short}   ⌘K Actions   ⌘⌫ Remove` on library tabs. Short labels: Copy GIF → `Copy`, Paste GIF → `Paste`, Copy Link → `Copy Link`, Paste Link → `Paste Link`, Copy Markdown → `Copy Markdown`, Paste Markdown → `Paste Markdown`, Download GIF → `Download`. The short label follows the **selected item** (a gated Klipy item shows `Copy Link` / `Paste Link`).

### Reduce Motion (closes the Phase 2/3 known gap)

- Follows `prefers-reduced-motion` (WebKit tracks the macOS Reduce Motion setting live). No separate toggle.
- When on: every grid and library tile shows a still image; only the **selected** tile animates. The Details preview animates (it is the selected item). Hover never starts animation.
- Still source: the provider's still rendition when the result carries one (GIPHY `*_still`, Klipy `jpg` rendition, loaded from the returned URL unaltered), else a first-frame capture of the preview drawn once to a `<canvas>` after load (Finer Gifs), after which the animated `<img>` is removed from the DOM so it stops decoding.
- When the selection moves, the old tile returns to its still and the new tile loads its animated preview.

### Theme (SETT-06, Amends 02/03 theme rule)

- `<html data-theme="light|dark">` always holds the **resolved** theme. `System` resolves from `matchMedia('(prefers-color-scheme: dark)')` and follows changes live; Light/Dark are fixed.
- CSS: light tokens on `:root` with `color-scheme: light`; dark tokens on `:root[data-theme="dark"]` with `color-scheme: dark`. The two `@media (prefers-color-scheme: dark)` blocks are removed. `main.ts` sets `data-theme` before mounting (no flash).
- Go sets the native appearance for both windows (`System` → follow macOS, `Light` → Aqua, `Dark` → DarkAqua) and the windows' background colour. The panel and Settings switch together on change, without reopening.
- The footer GIPHY mark (and the About mark) chooses the light/dark image from the resolved theme in script, not from a `<picture>` media query, so a manual theme never shows the wrong mark.
