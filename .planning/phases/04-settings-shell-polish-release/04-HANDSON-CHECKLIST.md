# Phase 4 hands-on checklist (run on the rebuilt, installed app)

Sources: human-check lists in 04-01..04-07 SUMMARYs + 04-REVIEW-FIX untested items.
Already covered by the VM test: Gatekeeper/first launch, ⌘V paste, ⌘↵ copy-only, About 1.0.0, Check for Updates "up to date".

## A. Settings window (≈5 min)
1. Tray → Settings…, and ⌃⌥⌘G then ⌘, → Settings is active and takes typing; ⌘, hides the panel first.
2. ⌘W / red button hide Settings and your previous app comes back. Esc does not close Settings.
3. Theme Dark / Light / System switches panel + Settings with no white flash; System follows a live macOS appearance change.
4. Open Gifsmith at login: check → appears in System Settings → Login Items; uncheck → removed.
5. NEW (WR-F01): with Settings closed, turn Gifsmith off in Login Items, reopen Settings → checkbox shows unchecked.
6. Accessibility off → Grant Access… shows the prompt; after granting, row shows "✓ On" within ~2 s.

## B. Keys & Search (≈5 min)
7. Keys → GIPHY → Change Key…, paste, Save → "Saved · ends in XXXX"; Test → "GIPHY accepted the key."
8. Content rating G then R → trending changes after reopening the panel.
9. GIFs per page 48 → longer first page, scrolling still loads more.

## C. Hotkeys (≈5 min)
10. Record a new Open shortcut; press it from another app → panel toggles. Tray shows the new shortcut.
11. Set Favorites ⌃⌥⌘F and Recents ⌃⌥⌘R → each opens its tab; pressing again hides.
12. Recording captures the current Open combo without firing it; Esc / Tab / Shift+Tab cancel with no error left (WR-F05/F06).
13. Start recording, click into another app → Open shortcut still works.
14. NEW (WR-B02/B07/WR-06): clear Open's shortcut → tray "Open Gifsmith" shows no shortcut; "Reset to Default" is enabled and restores ⌃⌥⌘G.

## D. Downloads & grid (≈5 min)
15. Downloads → Choose… → folder sheet; pick a Desktop folder, allow → ⌘S saves there.
16. Hide original file names on → ⌘S saves gifsmith-{id}.gif, then gifsmith-{id} (2).gif.
17. Search results Large, Trending Small → 3 vs 5 columns; right-click a GIF opens the action menu beside it.
18. Klipy GIF: ⌘S → "Klipy GIFs can't be downloaded yet."

## E. Motion, About, Updates (≈3 min)
19. Reduce motion on → only the selected GIF animates, others show a still (no blank tiles).
20. About in Light and Dark: links open the right pages; GIPHY mark switches with theme.
21. Updates section looks right in Light and Dark.
