<objective>
Walking-skeleton tracer for Gifsmith: scaffold the Wails v3 app at the repo root and prove the first half of the core loop end to end — ⌃⌥⌘G shows a non-activating floating panel that takes typing immediately, Enter copies the bundled sample GIF to the clipboard as a file, ⌘V pastes it animated into TextEdit with no Accessibility permission — then expand it into a proper menu-bar app (tray menu, no Dock icon, panel on the cursor's screen).

Purpose: This is the phase's first go/no-go evidence. Typing into a non-activating panel (research Pitfall 1) is the least certain native behavior in the whole product, so it is proven on the agent's earliest, best context and confirmed by the user at the tracer gate before anything else is built (D-01).
Output: Scaffolded repo (Wails v3 beta.30, Svelte 5, pnpm), `internal/platform` (CopyFile, FocusWebView, CursorScreenWorkArea), `internal/shell` (panel, hotkey, tray, placement), `internal/services.ActionService.Copy`, `frontend/src/App.svelte`, embedded `sample.gif`, ad-hoc `bin/gifsmith.app`.
</objective>
